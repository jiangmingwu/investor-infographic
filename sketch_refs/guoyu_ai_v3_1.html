郭宇的主线不是“ChatGPT 会回答问题”，而是 Claude Code + Skill + Tool Use 让想法直接变成行动：查资料、装工具、写代码、运行、交付。

Skill 成拐点

他口中的“去年10月”：Claude Code 的 Skill / Agent 模式，让工作方法可写成 Markdown。

Tool Use

模型会用工具

Web Search、读文件、调用工具、现写代码，不再只是给你一段聊天答案。

Token

软件形态变了

固定代码变成动态流动的 Token；背后依赖 GPU、推理、电力与数据中心。
