现场 Demo：AI 搭建个人网站，不是 PPT 想象

上集里他现场让 Claude Code 给主持人/记者做个人网站：这段是整场分享最重要的“能力证明”，因为它把搜索、理解、设计和代码串成了完整流程。
02 / Demo
1. 提需求“帮我做一个介绍车畅记者各种写作的网站”，技术栈不懂也没关系。
2. 自己搜索Claude Code 调 Web Search，识别记者背景、代表作品和已有网站 changche.com。
3. 追问细节它会问网站风格、技术站、分类搜索、最后部署到哪里。
4. 运行代码开始用 Python / 代码生成项目，设计系统、组件和页面。

7 个设计 Skills

他让模型加载设计 Skill；本机没装时，Agent 自己搜索、安装，最后成功装了 7 个设计相关 Skills。

2-3 分钟出结果

现场说大概两三分钟，并强调这已经算慢；之后还可以做中日英三语版本。

WordPress 被绕开

主持人以前依赖 WordPress；郭宇说未来不一定需要平台，唯一依赖的是推理需求。
