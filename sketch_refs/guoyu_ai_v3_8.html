观众提问后的落点：学生、商业和社会分配

最后一组内容来自主持人和观众追问：年轻人学什么、AI 还能做什么、商业上怎么用，以及生产力暴涨之后社会会变成什么样。
08 / 落点

大学生：先会用 Agent

观众问年轻人该学什么。他说现在可以学好 Claude Code / 编码 Agent，在 三到六个月形成短期优势；之后单纯学工具也会失效，因为会更自动化。

商业：一对一营销

他提到 Automatic Marketing Agent：不是批量投广告，而是在网上找到具体某个人，发短信、打电话、写邮件，甚至送礼到家门口。

农业：长期实验

他用日本水果育种举例，蓝莓、晴王这类长期实验天然适合 Agent：反复试、长期跑、记录结果。

社会：生产力与分配错位

AI 公司赚钱、利润提升、同时裁员；岗位减少会压低消费，服务更便宜又会加剧通缩，未来会更不稳定。

他的行动建议：不要只停留在聊天或围观，必须亲自用；当“思考到行动”的隔阂被弥合，普通人也能拿每月 200 美元级别的工具去做以前公司级别的实验，长期再回到想法、直觉和判断。
