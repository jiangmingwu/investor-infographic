2核心观点
软件的终结未来不是先设计固定软件，再交付用户；而是把需求、文件、登录态交给 Agent，由 GPU 推理按需“现写代码”。

Skill 是工作流文档化把每天怎么做事写成 Markdown，Claude Code 按文档自动运行，边写代码边调用工具。
Tool Use 改变搜索人不再手动 Google；Agent 自己 Web Search、安装 Skill、读本地文件，再把结果组装成软件。
他的底层判断：只要你能说清楚想法，就能让模型把“想法到软件”的距离压到极短。
3知识工作的冲击
1人≈1万短期是个人能力爆炸；长期则意味着许多岗位不再需要人。
6个月他把“长期”压缩到半年级别，强调变化速度极快。
24×7×365OpenClaw/Agent 可常驻电脑，持续处理邮件、任务、推演公司。
SaaS重排图片、文档、网站、WordPress 式工具都可能被“按需软件”冲击。
最先受影响的是程序员，尤其初级程序员：他认为许多硅谷公司已经减少初级招聘，因为 Claude Code 的速度、成本和沟通摩擦更低。
