机制拆解：Skill、Tool Use、Memory、Loop

如果只说“Claude Code 很强”，信息太浅。真正值得解释的是：它为什么能把知识工作拆成可执行流程。
03 / 机制
Skill

方法可封装

把专家经验、日常流程、判断规则写成文档；Agent 按文档执行，不只是吃提示词。

Tool

工具可调用

搜索、读网页、写代码、跑脚本、装依赖，模型自己把答案变成行动。

Memory

上下文可积累

每个 Agent 都可能有自己的记忆；组织摩擦会被“共享上下文”降低。

Loop

结果可迭代

不再一次性交付答案，而是实验、失败、修复、重跑，直到某条分支更有效。

郭宇原话层

他把工作写成 Markdown 文档，再让 Claude Code 根据文档现写代码、自动运行；这就是“软件的终结”的底层含义。

专家解读层

这更像一个微型操作系统：自然语言是入口，Skill 是程序包，工具调用是 I/O，Loop 是调度与反馈。
