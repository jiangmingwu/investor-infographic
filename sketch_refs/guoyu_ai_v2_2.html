Skill：把工作方法写成流程

他真正看重的不是聊天，而是 Skill + Tool Use：把专家方法、日常流程、设计经验写成文档，让 Agent 按流程自动执行。
主线 02
Demo 案例

个人网站重构

现场让 Claude Code 读取记者个人网站，调用 Web Search，理解作品与背景，再用设计 Skill 改造页面。

具体数字：Demo 中自动安装了 7 个设计相关 Skills。这个数字有意义，因为它说明“专家方法”可以被打包调用。

Skill 不是提示词更像一本可执行的工作手册：早上做什么、查什么、怎么判断、怎么交付。
Tool Use 改变搜索人不再逐条 Google；Agent 自己搜索、安装工具、读文件，再把结果组合成产品。
平台依赖下降WordPress、SaaS、模板工具不再是唯一入口；按需生成会重排这些产品。
