人类最后的优势：不是会做，而是有 insight

下集主线：Agent 会替代大部分“思考流程”，但人仍有不按常理的直觉、想象力和感受力

实验逼近智慧

把问题拆成大量尝试，让 Agent 在后台循环、研究、生成、筛选；郭宇自己的例子是睡前跑 1000 个 loop。

loops
auto-research 的价值：代替大部分人不愿意做、也很难持续做的研究和发散。
H人的路径
直觉与想象力

人可以从毫不相关的事物跳到毫不相关的想法；概率模型按分布搜索，遇到“不按常理”的思路反而难预测。

insight 不是工具熟练度。 它来自读过的书、成长经历、心理状态、性格、童年经验，以及对世界的感受。
想法重新变贵。 以前常说“想法不重要，行动重要”；现在行动门槛被 Agent 压低，独特想法变成稀缺资产。
?给使用者的提醒
99.999%他形容：普通人用 Claude Code，也像背后有一个强过绝大多数人的模型给你“输入功力”。
10小时如果一天刷短视频十小时，只追求多巴胺，就更容易被 auto-research 替代。
6个月现在学会用 Claude Code 可以短期卷赢别人，但工具优势本身会快速贬值。
  • 不要只练提示词。 要训练判断、感受、品味和异常联想。
  • 不要等确定性。 先做出来，再用结果校正直觉。
  • 比别人更快发布。 被复制不可怕，速度与持续迭代才是护城河。
一句话总结：Agent 会越来越会“想”，但更像概率空间里的搜索；人要保住优势，需要提供它搜不到的方向。
案例：OpenClaude 创始人回应被复制：发布速度要比别人复制速度更快。
场景：用 Claude Code 连接石头扫地机器人，让本地 Agent 自主判断哪里脏、何时扫。
