势宏观判断
中国缺卡，美国缺电他认为美国模型强但数据中心受电力约束；中国有电但高端卡与编码训练资源受限。
推理成本 1/10他提到 Rubin 架构后，明后年 AI 数据中心推理成本可能降到当前十分之一。
6-12个月代差他判断中美在编码模型上仍有代差，许多国内模型通过蒸馏 Claude Opus 跟进。
生产力 vs 分配AI 公司赚钱、利润提升、同时裁员；工作减少与服务降价可能带来通缩压力。
做普通人的应对
1
先把工具用起来三到六个月内，学会 Claude Code / Agent 仍能形成短期差距。
2
把想法拆成实验不要只写计划；让 Agent 反复跑、反复试，低成本淘汰失败路径。
3
转向高客单价场景Automatic Marketing Agent 可点对点找人、发短信、邮件、送礼，更适合高价值客户。
4
训练不可外包部分直觉、审美、世界经验、价值判断，是你给 Agent 的方向盘。
