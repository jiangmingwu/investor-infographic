# 管理文化：有特色、有证据、值得借鉴

本页服务于一个问题：这家公司怎样对待员工、组织协作或兑现经营原则，其中哪些具体做法值得学习？不是把公司的成功、规模或战略换一个标题再写一遍。适用于原版四图中的《管理文化》，不改变其他三张图的分工。

## 选材顺序

1. 优先调查员工真正得到的东西：薪酬、保障、休假、内部晋升、员工自主权、公平待遇，以及这些承诺如何执行。不是每家公司都必须有“福利很好”这一结论。
2. 再找独特的组织或经营纪律：如何授权和反馈、如何处理利益冲突/腐败、如何兑现对顾客的承诺。可纳入有明确约束和执行证据的定价纪律；不能把低毛利财务结果自动解释成顾客至上的文化。
3. 默认精选 1-2 项，第三项必须提供真正不同的机制。一个强案例好于三个泛泛标题。同一制度的福利、满意度、留任率不要拆成三种文化。

每项都必须回答：**具体怎么做？证据能证明什么？特色在哪里？** 特色可以是明确的权利、规则或执行选择，不必虚构“行业唯一”。先调查最有希望的候选，再保留证据最强的项，不为填格子扩大搜索到无关战略。

## 证据标准

- 首选员工手册、薪酬/福利政策、年报/可持续发展报告、公开纪律处分或制度执行记录、负责人有出处的访谈；用可信媒体、员工调查等补充交叉核验。匿名评论可以提供线索，不能单独证明全公司的待遇。
- 官网招聘页能证明“公司公布了某项政策”，不自动证明执行覆盖或员工普遍满意。区分 `published_policy`（公开制度）与 `reported_practice`（已有公开执行案例/统计），文案分别写“公司规定/公布”与“据某报告/案例”。后者也不等于独立审计结论。
- 有可靠数字就展示最有解释力的 1-2 个：覆盖多少人、带薪多少周、晋升比例、明确待遇等。无数字但有具体权利、责任人、触发条件、处理流程和案例，也可以入选。**不要为量化而填员工总数、招聘量、研发人员或营收。**
- “工资明显高于同行”“行业最好”等比较，必须核对同地区、同年份、同类岗位、全职/兼职、基本工资/总报酬、均值/中位数及分母。不能用高管薪酬比普通员工，不能用一个国家福利代表全球。比较基准不可靠时只写已核实的待遇，不下优越性结论。
- 集团/子公司/加盟商/承包商范围必须区分。结论若只适用于总部或某地员工，正文用短限定语，完整口径放底稿和脚注。中文括注解释陌生制度名，金额继续按 USD/美元及日期明确的汇率口径展示。
- 每项记录来源标题、发布/适用时间、原始 URL、页码或段落定位。核对是否仍适用；历史政策或案例标明年份，不冒充现行制度。遇到有可信来源的执行争议，限定结论或补充一句关键限制，不能只挑正面材料塑造“模范企业”。

## 明确剔除与边界

| 候选内容 | 处理 |
| --- | --- |
| “以人为本”“有竞争力的工资”“零容忍腐败”，没有具体规则或案例 | 不入选，继续查证；查不到就删 |
| 宁德时代的“高速校招扩张组织”、员工净增、研发中心布局 | 不能证明独特管理文化，移到公司档案/战略资料或省略 |
| 工厂一线员工享有明确带薪假、晋升通道或安全停工权 | 可以研究；不能因为出现“制造/生产”两个词就误判成战略 |
| 客户低价承诺有明确规则、决策约束及可核验的执行例子 | 可入选；只有毛利率低或市场份额大不够 |
| 反腐制度规定举报保护、调查独立性、问责程序并有执行案例 | 可入选；普通合规口号不够，不能把调查指控写成已定罪 |
| 公司“扩产”“加大研发”“扩大市场份额” | 属于经营战略，不是本页选材 |

涉及 Costco 一类案例，必须区分加价率 `(售价-成本)/成本` 与毛利率 `(售价-成本)/售价`，核对商品范围、自有品牌/其他品牌、历史/当前和例外；不得把未核实的“14%”写成全公司的当前毛利率上限。

## 底稿与文案

保留原来的渲染字段 `lens / principle / practice / case_or_number / source`，新增三项仅供研究审查，不自动堆进图片：

- `distinctiveness`：具体特色及学习价值，不能只是复述标题；不要求夸成独有或行业第一。
- `evidence_scope`：适用人群、地区/组织、时间、数字定义及限制。
- `evidence_status`：`published_policy` 或 `reported_practice`。

如提出优于同行的比较，底稿再提供 `comparison`：本公司口径与数值、同行口径与数值、可比性说明、双方来源。不作此类比较时不必增加字段。

正文可采用自然中文：**具体特点标题 + 怎么落实 + 一个数字或案例**。可在同一卡内用一句话解释值得借鉴的机制和适用条件，不增加强制的“管理启示”“投资含义”或底部总结模块；不要把效果推测写成事实。图上保留 `做法：`、`案例：`/`数字：` 的简短标签，原有配色与语气不变。

查不到任何足够具体的项时，记录已查来源和局限，报告该页尚未完成，不编造卡片、不把空白页当成审核通过。不要把“未找到公开证据”写成“公司没有福利”。

## 排版与发布检查

- 沿用公司原有 Logo、配色、手绘小图标和版式语言；图标对应工资、休假、授权、客户承诺或伦理等实际内容，不是统一套工厂或金币。
- 强证据置于卡片视觉重点，正文讲规则，来源/日期留在紧邻正文下方的底部备注；缩短多余画布。只有一项就做一项，不缩小字硬塞，也不保留无意义空框。
- 本页不重复《经营之道》的业务优势和战略，不重复《经营全景》的财务看板。管理机制确实支撑竞争优势时可简短关联，不复制整段内容。
- 审核者必须打开原始来源，逐卡判断证据是否支持标题、范围和特色，检查有没有有数字却答非所问、比较不可比、只重复口号、把计划当执行的情况。机械校验通过仅代表字段齐备，**不代表内容准确、有特色或视觉合格**。
- 改代码按当前 GPT-only 双轮独立审核规范；最终出图仍需实际查看 PNG，核对中文、图标、换行、无截断/重叠、来源和独立居中 `by 江明`。不启用邮件。

## 选材回归题

每次改本规则至少复核：招聘规模（应拒绝）、无案例的以人为本（应拒绝）、跨国家薪酬直接比高低（应拒绝）、一项有出处的员工权利（可入选）、制造员工福利（不按关键词误杀）、有执行证据的顾客承诺（可入选）、同制度拆三卡（合并）、没有强证据（报告缺口）。这些是语义审查题，不是假装自动程序能判断真实性。
